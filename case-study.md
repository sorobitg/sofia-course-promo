# Case Study: Sofia's Course Promo Campaign

## Overview

This document captures the creative and strategic decisions behind the promotional materials for **Sofia's Course** — a transformative online program designed to help students build clarity, confidence, and measurable results.

---

## Objectives

- Build awareness and excitement ahead of the course launch
- Communicate the transformation students can expect
- Drive sign-ups through a compelling visual and narrative identity
- Create reusable assets for social media, email, and landing page promotion

---

## Target Audience

| Attribute | Description |
|-----------|-------------|
| **Age range** | 22–45 |
| **Goals** | Personal growth, career advancement, mindset shift |
| **Pain points** | Overwhelm, lack of direction, inconsistent habits |
| **Channels** | Instagram, TikTok, email newsletters |

---

## Creative Direction

### Visual Identity

- **Color palette:** Deep purples and violet gradients to evoke transformation, intuition, and premium quality
- **Typography:** Clean, modern sans-serif with bold weight for impact headlines
- **Tone:** Aspirational yet approachable — Sofia speaks as a guide, not a guru

### Key Message

> *"You already have what it takes. Sofia's method helps you unlock it."*

---

## Asset Breakdown

### Cover Image (`sofia-cover.png`)
- Used as the hero image on the landing page and as the video poster
- Should feature Sofia in a confident, warm pose against a minimal background
- Dimensions: 1920×1080 (16:9)

### Slide Deck (`slide-1.png` → `slide-6.png`)

Each slide corresponds to one course module:

| File | Module | Topic |
|------|--------|-------|
| `slide-1.png` | Module 1 | Foundation — Why most people stay stuck |
| `slide-2.png` | Module 2 | Mindset — Rewiring limiting beliefs |
| `slide-3.png` | Module 3 | Strategy — Building your personalized roadmap |
| `slide-4.png` | Module 4 | Execution — Daily systems that create results |
| `slide-5.png` | Module 5 | Momentum — Staying consistent when life gets hard |
| `slide-6.png` | Module 6 | Mastery — Sustaining transformation long-term |

Slides follow a consistent visual template: module number, headline, one key takeaway sentence, and a background gradient matching the brand palette.

### Promo Reel (`final-reel.mp4`)

- **Format:** Vertical (9:16) for Reels / TikTok; also export a 16:9 cut for YouTube/email
- **Duration:** 60–90 seconds
- **Structure:**
  1. Hook (0–5 s) — Bold text: *"What if everything could change in 6 weeks?"*
  2. Problem (5–15 s) — Relatable pain points in quick cuts
  3. Solution (15–35 s) — Sofia on camera introducing the method
  4. Social proof (35–50 s) — Student testimonial snippets or text quotes
  5. CTA (50–90 s) — Clear enrollment call-to-action with URL overlay
- **Music:** Uplifting, royalty-free background track (60–70 BPM)
- **Captions:** Burned-in subtitles for silent autoplay environments

---

## Production Workflow

1. **Design** — Create slides in Figma/Canva following brand guidelines
2. **Photography** — Shoot cover and supporting images in consistent lighting
3. **Video Edit** — Assemble reel in CapCut / Premiere Pro from raw footage
4. **Export** — Export `final-reel.mp4` at 1080p, H.264, AAC audio
5. **Review** — QA on mobile and desktop before publishing
6. **Deploy** — Upload all assets to `assets/` folder; update `index.html` src attributes
