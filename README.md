# 🎨 Sofía Course Promo (Animated Campaign)

A Pixar-style branded character campaign designed for Instagram Reels and carousel marketing.

## 🚀 Features

* Custom character (Sofía)
* Scroll-stopping visual design system
* Animated reel structure (12–18 sec)
* High-converting CTA layout
