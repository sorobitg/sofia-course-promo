# Sofía Course Promo — Animated Campaign Case Study

A Pixar-style branded character campaign landing page designed to increase engagement and conversions for a digital course.

## Overview

This project showcases a full animated campaign case study for **Sofía**, a custom character built to transform passive social media scrollers into active, paying students.

## Project Structure

```
sofia-course-promo/
├── index.html   # Single-page campaign case study
├── styles.css   # Design system — warm palette, animations, mobile-first layout
├── script.js    # Scroll-reveal, counter animation, parallax & eye-tracking
└── README.md
```

## Features

- **CSS character animation** — Pixar-inspired Sofía with blinking, waving, and eye-tracking
- **Scroll-reveal sections** — IntersectionObserver-powered entrance animations
- **Animated stat counters** — Ease-out-quart number animation on scroll into view
- **Parallax glow & particles** — Mouse-driven depth layers in the hero
- **Fully responsive** — Mobile-first, adapts from 320 px up
- **Accessible** — Semantic HTML, ARIA labels, reduced-motion support

## Usage

Open `index.html` directly in any modern browser — no build step required.

## Campaign Strategy

The page follows the proven 5-step conversion framework:

1. **Hook** — Stop the scroll in the first frame
2. **Problem Awareness** — Mirror the viewer's frustrations
3. **Value Delivery** — Deliver a quick win
4. **Authority Positioning** — Establish credibility
5. **Offer + CTA** — Single, low-friction conversion action
