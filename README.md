# sofia-course-promo

Promotional website and assets for **Sofia's Course** — a transformative online program.

## Project Structure

```
sofia-course-promo/
│
├── assets/
│   ├── sofia-cover.png        (hero cover image)
│   ├── slide-1.png            (Module 1 — Foundation)
│   ├── slide-2.png            (Module 2 — Mindset)
│   ├── slide-3.png            (Module 3 — Strategy)
│   ├── slide-4.png            (Module 4 — Execution)
│   ├── slide-5.png            (Module 5 — Momentum)
│   ├── slide-6.png            (Module 6 — Mastery)
│   └── final-reel.mp4         (promo reel — export and add before launch)
│
├── index.html                 (landing page)
├── case-study.md              (creative & production case study)
└── README.md
```

## Getting Started

1. Add all image and video assets to the `assets/` folder (see `case-study.md` for specs).
2. In `index.html`, uncomment the `<img>` and `<video>` tags once assets are in place.
3. Open `index.html` in a browser to preview the landing page.
