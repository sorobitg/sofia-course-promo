# Sofía Course Promo — Animated Campaign

A character-driven animated social media campaign designed to increase engagement and conversions for a digital graphics course. The package includes a full 15-second reel broken into 9 slides, a responsive HTML landing page, and a client-ready case study.

## 🚀 Usage

### View the landing page
Open `index.html` in any modern browser — no build step required.

### GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages → Source** and select the `main` branch, root `/`.
3. Your promo page will be live at `https://<username>.github.io/sofia-course-promo/`.

### Add the reel
Place your compiled `final-reel.mp4` inside the `assets/` folder. The landing page phone mockup references `assets/final-reel.mp4`.

### Replace SVG placeholders with real assets
Swap the `.svg` placeholder files in `assets/` with your final rendered PNG/JPG slides or keep the SVGs — they scale perfectly at any resolution.
